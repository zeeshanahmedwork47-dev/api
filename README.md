# API Testing (Flutter Project)

This repository contains a Flutter project where I experimented with different APIs, authentication flows, and database connections. The project covers everything from fetching dummy data to building a fully functional authentication system integrated with a custom backend.

---

## 🚀 Features Implemented

### 1. Fetching Posts (JSONPlaceholder API)

* Fetched a **single post** and a **list of posts**.
* Displayed the data in the Flutter app.

### 2. User Authentication (DummyJSON API)

* Implemented a **login screen** using DummyJSON API.
* Displayed a user-specific **homepage** after successful login.

### 3. Full Authentication App (Custom Database)

* Built a complete authentication system:

  * Login
  * Sign Up
  * Home Page
  * Logout
* Backend connected with **MySQL database** via **PHPMyAdmin**.
* API endpoints built using **XAMPP server**.
* Flutter frontend communicates with the backend API for all authentication operations.

---

## 🛠️ Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** PHP (XAMPP Server)
* **Database:** MySQL (PHPMyAdmin)
* **APIs:**

  * JSONPlaceholder (Fake API)
  * DummyJSON (User Auth API)
  * Custom REST APIs for authentication

## ⚡ How to Run

1. Clone the repository

   ```bash
   git clone https://github.com/your-username/api-testing.git
   ```
2. Navigate into the project folder

   ```bash
   cd api-testing
   ```
3. Run Flutter dependencies

   ```bash
   flutter pub get
   ```
4. Launch the app on your emulator/device

   ```bash
   flutter run
   ```
